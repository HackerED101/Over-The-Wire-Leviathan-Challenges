# OverTheWire Leviathan Wargame Tutorial

This repository contains a step-by-step tutorial for completing the **Leviathan** wargame on **OverTheWire**. The **Leviathan** wargame focuses on basic Linux skills and some simple vulnerabilities. Each level introduces you to different security challenges, and as you progress, you will gain more knowledge of *nix systems and tools.

## Prerequisites

Before starting, you will need:
- A terminal or SSH client
- SSH access to the **Leviathan** wargame (using the credentials provided for each level)
- Basic understanding of Linux commands

## How to Use This Tutorial

- Follow each level step-by-step.
- After logging in to each level, you will find clues, hidden files, and directories.
- Follow the hints and use tools like `ls`, `cat`, `grep`, `strings`, `ltrace`, `chmod`, etc.
- At each level, you will get a new password, which is needed to log in to the next level.

**Note**: The passwords you will receive at each level will be different from mine. Follow the instructions in this tutorial, and you will be able to retrieve the password for each level on your own.
